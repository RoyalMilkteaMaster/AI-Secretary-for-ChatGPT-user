AI 秘書由 Agent 協助設定的入口
版本日期 2026-10-08

請先閱讀本檔，再讀「助手交接指示.txt」與「操作手冊.html」。這兩份保留完整指令、保護機制與問題排查；「../docs/AI秘書完整操作圖解.pdf」是本人需要接手時的畫面參考，不是唯一的執行規格。

本版的分工
1. 你負責檢查環境、依本人提供的非秘密資料填寫設定.json、執行教材工具、部署及回讀結果。不要叫一般使用者自己修改 JSON、複製命令或尋找資料庫識別碼；能由你查到並核對的值，由你處理。
2. 先確認你能存取整個資料夾並執行本機命令；若只有聊天或附件閱讀能力，就說明缺少的能力，請本人改用可操作本機的 agent。若缺 Node.js，說清楚缺少什麼，按本機環境的工具與批准規則處理，不宣稱只有 PDF 就能自動完成部署。
3. 若具備已授權的瀏覽器工具，可處理一般導航、查找欄位及不涉及秘密的表單；遵守該工具的使用限制。登入、選擇帳號、OAuth 同意、二階段驗證及一次性連結碼，交由本人完成。不能操作瀏覽器時，才指向圖解頁面，每次一個動作。
4. 先收集：專用寄件 Gmail、收件主帳號、指定日曆，以及本人是否要長期使用。寄件與收件不能相同。只收帳號地址與服務識別，不索取密碼、金鑰、refresh token。
5. 先核對本人 ChatGPT 的自訂 MCP、工作模式及新專案功能，再部署雲端。圖解是當時介面參考，以本人現在畫面為準；不保證任一最低價方案皆可。
6. 開始前說明會在本人的 Cloudflare 與 Google 帳戶建立什麼、會寄到哪裡以及每日提醒時刻；已有授權涵蓋的必要操作不反覆問。每日提醒的最終啟用仍須完成驗收後由本人確認，不能預先把人工驗收標記為通過。

執行順序
第一階段：環境與帳號功能預檢。讀手冊第 1 步，執行離線測試，替本人填好自己的設定。
第二階段：建立服務並連接。執行手冊第 2、3、5 步，以及第 4 步的專案、外掛與工作模式連接；示範待辦留到第三階段。Google 長期授權選擇在此確認。每日寄信保持關閉。
第三階段：驗收完整一條流程。用教材固定 ID 新增一般示範待辦、修改同一筆期限、讀回只一筆；先 preview，再經本人確認只寄一封驗收信。本人在 Gmail 勾選後確認保存，關閉重開；聊天讀回同一筆 completed，下一封預覽排除它。
第四階段：示範下一步並清理。需要示範下一步時，先建立第二筆固定 ID 再預覽；取消且讀回教材的兩筆示範，確認沒有 active DEMO_，再做 ready-check。不要先啟用排程、再留下未清理的練習資料。
第五階段：本人明確確認驗收通過，才執行 ready-check --human-checks-passed、prepare --enable-daily 與部署。核對台北每日 09:00。下一次真正到點後，再由本人核對收件並讀回當日狀態；在那以前回報「已排程，首次到點收件待確認」。

清理示範必須在啟用每日提醒之前。所有保護機制與工具確認旗標保持不變。

重要限制
日曆只讀，待辦工具不能修改 Google 日曆。主帳號只授權日曆唯讀，專用寄件帳號的 SMTP OAuth 要求完整 Gmail 權限。Google 外部測試模式的這類 refresh token 七天失效；長期使用按技術手冊確認發布狀態並視情況重新授權。正式發布也不代表授權永不失效。
不可把離線測試說成 Gmail 已收信，不可用歷史圖片替代本人的實測，不改原作者服務、他人的帳號、既有真實待辦或其他排程。

每一階段回報
已經完成什麼 → 實際結果依據 → 還缺什麼 → 本人現在是否需要做一個動作。
最終交接列出本人服務網址、寄件與收件地址、每日時刻、已通過的實機驗收、首次到點收件是否已驗證，以及出現問題時如何停用與恢復。不含任何秘密。
