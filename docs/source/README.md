# 操作圖解來源

`build_guide.py` 產生 12 步 Word、示意圖與頁面索引。需要 Python 的 python-docx、reportlab、pypdfium2、Pillow，字型使用 Windows 的 Microsoft JhengHei。`screenshots/` 只有已遮蔽私人欄位的兩張歷史參考圖；腳本以 Word 圖片裁切隱去原製作註腳。

執行後從 Word 匯出 PDF，再逐頁檢查。示意圖依官方流程繪製，標示操作示意；不冒充實際截圖。Cloudflare 註冊依據：https://developers.cloudflare.com/fundamentals/account/create-account/ 。
