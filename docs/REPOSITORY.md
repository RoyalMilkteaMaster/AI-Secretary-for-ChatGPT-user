# 倉庫內容與版本分工

這個 GitHub 倉庫是給親友展示、下載與交給 agent 設定的分享版。`README.md` 是首頁，`docs/` 放完整圖解及流程，`setup/` 放可設定的通用程式包，`media/` 放成片、字幕與展示素材，`video/` 放可以重製的影片來源。影片來源中的程式是製作工具，設定秘書不用執行它。

原作者的正式服務、真實進度、私人帳號與憑證留在私人工作目錄，不從那個目錄整包上傳。每位使用者自行部署到自己的帳號。

2026-10-08 移除目前已停用的 CARD_GUIDE.md 與非必要的 MCP_BACKUP.md；舊版本仍可從 Git 歷史查閱。SETUP、PROJECT_INSTRUCTIONS、README 與 BUILD_LOG 更新為同一套 Gmail 互動提醒流程。

GitHub 的可見性與服務部署是兩件事。更新分享內容不會自動替任何人部署服務，也不會自動把私人倉庫改為公開。
