# AI 秘書示意動畫設計

概念：用同一張課程報名待辦，清楚連起「交給 agent 設定」與「每天交辦、看信、完成」。

- 1920×1080。背景 #F7F5EE，正文 #183A3B，重點 #137F83，完成 #21825A，白色紙張 #FFFFFF，淡綠 #E4F0EC，低彩提示 #4B6666，框線 #D1DFD8，手冊紅框 #B53732。
- 使用本地 Noto Sans TC，標題 72–96px、主要內容 48–62px、字幕 44px、示意標示 28px。單一字族符合使用者簡潔要求。
- 不放常駐側欄、功能三卡、裝飾線、小編號與偽資料。字幕保留底部160px。
- 所有 UI 以示意圖和原創排版呈現，禁止真實電腦截圖；影片明示操作示意，不冒充產品原樣。
- 每個鏡頭一個焦點；文字少、畫面留白，僅有語意需要時加下一個物件。
- 使用者選定的小機器人只在開場與收尾出現，圖片保持原樣，以整體移動表達到場與回應。
- 統一柔和24–36px圓角，輕陰影。場景間0.45秒連續推移或交疊，畫面不先清空。
- 場景內採spring-pop-entrance（power3.out，無彈跳）、scale-swap-transition與press-release-spring。保存/改期文字套用已安裝text-state-swap primitive，配色與字型遵守本檔。
