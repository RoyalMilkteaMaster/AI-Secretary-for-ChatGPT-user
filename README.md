# 把瑣事交給你的 AI 秘書

你是不是也跟我一樣，光是填行事曆、列待辦清單、記錄每件事的時間和地點，就覺得很麻煩？

好不容易整理完，看著一長串待辦事項，還得煩惱到底該先做哪一件，越想越煩躁。

這個專案就是為了解決這些困擾而打造的個人 AI 秘書。它串接了 **ChatGPT、Google Calendar 和 Cloudflare**，設定交給 Codex 帶你完成。除了 ChatGPT 本身的使用費用，其餘服務在免費額度內就能運作。

我們已經準備好 Agent 所需的設定包，以及 ChatGPT 的專案指示。你只要把這個 repo 的網址貼給 Codex，它就能一步一步帶你設定。

## 平時如何使用你的 AI 秘書

設定完成後，你的 ChatGPT 裡會多一個叫做「AI 秘書」的專案。你只需要在裡面像平常聊天一樣交代事情就可以了。

比方說，直接上傳一份 PDF 或貼上活動連結，告訴它：「我想參加這場會議，幫我安排一下。」它就會先檢查是否撞期，跟你確認時間後，再幫你加入 Google 日曆；需要改期時，也可以直接請它處理。

平常想到什麼待辦事項，也可以隨手告訴它，交代期限和急迫程度。它會幫你整理哪些要優先處理、哪些快到期限、哪些可以晚點再做，讓你不用每次都盯著一長串清單，煩惱到底該從哪件事開始。

每天早上 9 點，它還會透過 Gmail 寄來一封提醒信，整理好當天的行程與待辦。事情做完後，你可以直接在信裡勾選完成，之後回到 ChatGPT，也能查到最新進度。

## 怎麼開始？

準備一台 **Windows 電腦**，以及你平常用的 **Google 和 ChatGPT 帳號**。沒有 Cloudflare 也沒關係，Codex 會帶你免費申請，不用先買網域。

打開 Codex，把下面這段貼給它：

> 請幫我設定這個 AI 秘書：
>
> https://github.com/RoyalMilkteaMaster/AI-Secretary-for-ChatGPT-user
>
> 請先讀 AGENTS.md，確認我需要哪些帳號，再一步一步帶我完成設定。需要我操作時，一次告訴我一個動作。

接下來跟著它登入、授權，再一起確認秘書能正常運作。帳號功能和需要的設定，它會先替你檢查，不用自己研究一堆技術細節。
