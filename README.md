# AI 秘書

把事情交辦清楚，每天早上看提醒，做完勾選並保存。

這個專案提供完整設定包，讓你自己的 agent 協助建立 AI 秘書。日常在 ChatGPT 交辦待辦，Gmail 收到每日總覽；聊天和信件共用同一份進度。

## 日常怎麼用

> 下週五前寄出課程報名資料，請保存，再查回給我看。

期限變了，就更新原本那一筆。早上到 Gmail 看急件、近期截止、一般待辦與今日行程；事情做完後勾選，等畫面確認保存。

完成狀態會保存到自己的雲端資料庫。已完成的事項從下一封待辦總覽排除；後續還有工作，就繼續交辦下一步。

## 第一次設定交給自己的 agent

1. 下載本倉庫的 ZIP 並解壓縮，在 Windows 電腦用可讀取資料夾、執行命令的 agent 開啟它，例如 Codex 或 Claude Code。
2. 把 [開始這裡](setup/開始這裡.txt) 的文字貼給 agent，讓它先讀文件、核對環境，再協助設定。
3. 需要登入、授權或驗收時，由你接手；agent 可以指向 PDF 的紅框畫面。

一般使用者不必自己修改程式或輸入命令。只有聊天和附件閱讀能力的視窗，無法代替本機設定工具。

## 使用前需要知道

- 使用自己的 Cloudflare、Google 與 ChatGPT 帳號。兩個 Gmail 分別負責專用寄信與日常收信，不能共用作者帳號。
- 先核對 ChatGPT 的連線與工作模式功能；不同方案及工作區可能不同，不保證任一最低價方案可用。
- 本教材的 Google 日曆連線為**唯讀**。要改行程，回 Google 日曆修改；待辦期限則交由秘書更新。
- 首次部署保持每日寄信關閉。先驗收、清理練習事項，再由本人確認啟用台北每天 09:00。
- 不把密碼、權杖、個人設定檔或自己的服務資料提交到 Git。

設定包測試在 Windows 執行。歷史實機截圖用於辨認位置，不代表已替你的帳號完成設定。完整限制和 Google 授權維護方式見 PDF 與技術手冊。
